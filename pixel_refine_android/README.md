# Pixel Refine Android

This directory is reserved for the future Android implementation of Pixel Refine.

## Status
🚧 **Under Development** - Not yet implemented

## Planned Architecture
The Android version will follow the same MVC architecture as the desktop version:
- **Models**: Data models and repositories (shared with desktop where possible)
- **Views**: Android-specific UI using Qt for Android or native Android UI
- **Controllers**: Business logic controllers (potentially shared with desktop)

Stay tuned for updates on the Android implementation!
